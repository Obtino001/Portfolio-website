## 🚀 How to Run Locally

You can open `index.html` directly in any web browser, or serve it using any local static file server:

```bash
# Using Python
python -m http.server 3000

# Or using npx serve
npx serve .
```

Then visit [http://localhost:3000](http://localhost:3000).

## 🛠️ Customization
